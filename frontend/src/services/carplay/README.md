## Apple CarPlay Integration

This directory is intended for the frontend components of the Apple CarPlay integration.

**Implementation is currently blocked.**

The required native iOS components (Capacitor plugin, SceneDelegates, Info.plist modifications) cannot be created because the build environment does not have access to the `ios/` directory of the Capacitor project.

Once the native bridge is implemented and available, the frontend logic for state detection, rendering, and data transmission can be built here.
